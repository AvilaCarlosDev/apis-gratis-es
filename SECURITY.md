# Política de seguridad / Security policy

[Español](#español) · [English](#english)

## Español

Este repositorio es una lista documental: no ejecuta código de terceros ni aloja un servicio. Lo que sí puede ser un problema de seguridad:

- un **enlace malicioso** (phishing, malware) o un servicio que cambió de dueño y ahora es peligroso;
- un **ejemplo de código inseguro** (por ejemplo, que exponga una clave de API);
- **credenciales o claves** incluidas por error en un commit.

### Cómo reportar

Usa el aviso privado de vulnerabilidades de GitHub: <https://github.com/AvilaCarlosDev/free-apis-ia-espanol/security/advisories/new>. Para un dato desactualizado (sin riesgo), abre un issue normal con la fuente.

No incluyas claves reales en el reporte. Solo se mantiene la rama `main`.

## English

This repository is a documentation list: it does not run third-party code or host a service. What can be a security problem:

- a **malicious link** (phishing, malware) or a service that changed owner and is now dangerous;
- an **insecure code example** (for example, one that exposes an API key);
- **credentials or keys** committed by mistake.

### Reporting

Use GitHub's private vulnerability reporting: <https://github.com/AvilaCarlosDev/free-apis-ia-espanol/security/advisories/new>. For an outdated fact (no risk), open a regular issue with the source.

Do not include real keys in the report. Only the `main` branch is maintained.
